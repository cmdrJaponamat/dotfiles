# Niri Wallpapers

Канонический каталог обоев для активной `niri`-сессии.

Правило:

- новые обои для runtime-кейсов класть сюда;
- `hypr/wallpapers` считать legacy-архивом старых ассетов;
- пока каталог пустой, `niri` использует fallback на `~/.config/hypr/wallpapers`.

Рекомендуемые файлы для совместимости со скриптами:

- `home-sweet-home.jpg`
- `vimCheatSheet.png`
